01 / UPLOAD

Upload photographs.

여러 장의 사진을 한 번에 올릴 수 있습니다. 촬영일, 카메라, 조리개, 셔터스피드, ISO와 색상 정보를 자동으로 정리합니다.

JPEG · MULTIPLE
Upload process 사진은 최대 가로 1920px JPEG로 최적화되어 저장됩니다. 촬영 날짜는 EXIF 정보를 우선 사용하며, 색상은 이미지 분석 결과에 따라 자동 분류됩니다.

04 / LOCATIONS

Manage photo locations.

GPS가 남아 있는 기존 사진의 위치를 자동 복구하고, 위치가 없는 사진은 장소 검색 또는 좌표 입력으로 직접 지정합니다. 자동·수동 위치는 모두 같은 location 구조로 저장되며, 화면에는 시/도 + 시/군/구 수준으로 단순하게 표시합니다.

Manual location assignment
사진을 하나 또는 여러 장 선택한 뒤 장소를 검색하세요. 검색 결과를 적용하면 GPS 자동 복구와 동일한 상세 location 구조로 저장됩니다. 정확한 좌표·도로·장소명은 내부에 보존하지만 기본 표시명은 시/도 + 시/군/구 수준으로 통일합니다. 한 장만 수정하고 싶다면 그 사진만 선택한 뒤 새 위치를 적용하면 됩니다.
장소 검색 및 좌표 주소 변환: OpenStreetMap Nominatim · © OpenStreetMap contributors
Original file location recovery
SD카드의 공통 상위 폴더를 한 번만 선택하면 하위 폴더까지 모두 읽습니다. 예를 들어 DCIM을 선택하면 101NZ_FC, 102NCZ_5, 103_FUJI 안의 파일을 함께 검사합니다. 홈페이지에 이미 위치가 저장된 사진은 건너뛰며, 원본 자체는 업로드하거나 수정하지 않습니다. JPEG/JPG를 우선 사용하고 RAW 파일은 이름 매칭 참고용으로 함께 인덱싱합니다.
사진을 하나씩 고를 필요 없습니다. DCIM처럼 세 카메라 폴더를 함께 담고 있는 상위 폴더를 선택하세요.
